# Wagnerka — práce a termíny

Vyplňovací list pro PANEL-PROJEKT s.r.o. k dokumentaci renovace fasády
ZŠ Wagnerovo náměstí v Berouně.

**Živě:** https://frantisekdron.github.io/wagnerka/

Statická stránka, žádný server. Odpovědi i fotky se drží v prohlížeči toho,
kdo vyplňuje (localStorage); odesílají se tlačítkem — souhrn e-mailem,
fotky jako jeden stažený soubor k příloze.

Zdroj a generátor: `build.py` v projektové složce studia.
